# Centralize Notifications - Tasks

## 1. Create NotificationService and register MessageService globally

- [ ] Add `provideAnimations()` to `apps/admin/src/app.config.ts` providers.
- [ ] Add `MessageService` to `apps/admin/src/app.config.ts` providers (provided once, globally).
- [ ] Create `apps/admin/src/core/notifications/notification.service.ts`:
  - `@Injectable({ providedIn: 'root' })`
  - Inject `MessageService`.
  - `success(detail: string)`, `error(detail: string)`, `warn(detail: string)`, `info(detail: string)`.
  - Success life 3000ms, error life 5000ms. Summary text generated by the service.
  - No `key` unless a documented reason exists.
- [ ] Create `apps/admin/src/core/notifications/notification-messages.ts` with a message map (one place for all strings, e.g. "Product created", "Order updated", "Customer deleted").
- [ ] Grep verifies `MessageService` appears only in `app.config.ts` and `NotificationService`.
